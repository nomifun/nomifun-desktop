# R25：SSH Glob 命令生成

范围：nomifun-ssh/src/sink.rs 的 list_command/sh_quote_glob/list_files；追踪 nomi-agent 的 SshGlobTool 和 SshBackend 契约。Glob 明确只支持 POSIX 单层 *、?、[...]，不承诺递归 ** 或完整 shell 表达式。

## R25-01 与证据

旧 blacklist 遗漏重定向等 shell 语法：输入 input > victim 会覆盖 victim；空格拆成多个 pattern；--help 被 ls 当选项；包含 $/分号的合法字面前缀又被整体引用，连正常通配符也失效。

新增测试直接运行生产 list_command，解释器为本机 Git for Windows 的 sh，所有文件均为 tempfile 创建的自有夹具，不连接 SSH、不碰用户文件。

- 第一轮夹具缺少 /usr/bin:/bin，连普通通配符也失败。该轮不能作为四个问题的可靠基线，记录但不计红→绿。
- 补上 PATH 和 command -v ls 前置检查后，旧实现 1/4：普通范围/通配符通过，四个缺陷失败。victim 内容实际变成 input + 换行，空格模式额外返回 unrelated.rs，--help 返回帮助文本。
- 日志：临时目录 nomifun-review-r18-2EEsPY/ssh-glob-before-valid-fixture.log。

## 修复与整理

- 改成允许 glob 运算符及字面安全字符，其他字符逐字符 shell 转义；不再依赖难以穷举的危险字符 blacklist，也不整体关闭合法通配符。
- 移除 ls。用作用域隔离的 subshell + for/test/printf 返回原始文件名，避免 ls 的选项解析、终端/QUOTING_STYLE 引用及对外部 ls 命令的依赖。无匹配返回空；用 -L 保留悬空符号链接。
- 循环变量不写入持久 shell；命令保持单行，兼容后续 sentinel 拼接。
- 依照工具声明只支持 POSIX glob；~ 和反斜线按字面字符处理，不再意外引入额外 shell 展开。输入控制字符仍由既有路径校验拒绝。

## R25-02：搜索/列表结果语义（续审已验证）

- 四项旧行为失败：把 timed_out 的部分输出当成功；忽略非零状态；rg 无匹配再次用 grep 查；rg 错误被回退及 || true 隐藏。修改前 sink 测试 11/4，修复后全部通过。
- 搜索只按工具可用性选择一次；仅退出 1（无匹配）归一为成功空结果，其他状态和 stderr 诊断保留。不再在无匹配/错误时换引擎，避免重复遍历和不同正则语义导致的假阳性。
- grep 回退使用扩展正则 -E，支持常见的分组/或；仍不承诺其正则方言与 Rust ripgrep 完全一致。路径 - 改为 ./-，不误读 stdin。
- 搜索和列表共用 command_stdout：超时或非零状态返回 Err，不把部分匹配伪装成完整结果；run_command 仍保留显式状态 API。删除只有一处调用的 run_with_budget 转发包装。
- 引擎参数和退出码放在 subshell，保持单行，不污染持久 shell 的位置参数/状态变量；无匹配在继承 set -e 时也不会中止外层 shell。
- 最终 cargo test -p nomifun-ssh --lib -- --test-threads=4：30/0。新增九项测试包含四项红→绿、真实 Git POSIX sh/grep 的回退、扩展正则/无匹配/错误/引用路径、工具缺失诊断、单独 - 文件及状态隔离。
- 搜索分支选择的故障注入使用真实 shell 中的受控 rg/grep 函数；回退语义另调用真实 /usr/bin/grep，未将函数注入说成真实 rg 集成。日志 ssh-search-before / ssh-search-final。
- 进程边界检查通过；仅格式化新增测试。未重复 UI，无真实远端集成。
