# 插件架构收敛：当前支持范围与实施记录

日期：2026-09-15。用户已批准执行审查建议的第一、第二、第三批及文档同步。本页是本次收敛的范围入口；不再等待历史 A/B 方案选择，不启动更多开放领域。

状态：上述代码收敛已完成；定向/集成测试 213 项、聚合检查、合同检查及 Windows desktop check 通过，失败修正与证据见发布台账 §2.6。验证发生于提交前工作区，交接以包含本记录及对应代码的实际提交为准；尚未发布，正式安装包、真实模型及 macOS 实机验收不由源码测试替代。

目标：尽快交付结构清楚、可验证的插件能力，尽可能允许用户组合和替换 Agent 能力，而非替换任意宿主部件。正式默认仍为内置 Agent、模型和 UI；插件 Agent 页面仍需宿主显式开启实验开关。

## 1. 两个方向独立验收

| 方向 | 完成标准 | 不构成完成的情况 |
|---|---|---|
| 系统能力可插拔化 | 用户在 Agent 配置选择能力/实现，保存后实际调用使用选定实现 | 只有接口、合同、注册信息，或仅允许增加同类工具 |
| 插件插入生命周期 | 已有运行时在明确阶段调用插件，输入输出、顺序、授权和失败行为可验证 | 声明了 hook，但没有运行消费者；不能据此宣称底层实现已可替换 |

普通工具可以发布独立 capability，由用户选用自己的并取消系统同类工具，不覆盖系统 ID，也不要求每个工具都建立 Role。系统内部依赖的替换则需要稳定合同、实现选择和实际派发三者闭合。两条方向共享身份、冻结快照、权限与执行设施，不互相作为完成证明。

## 2. 实际支持矩阵

以下是已接线范围，不承诺各插件来源对称，也不以底层适配器存在推断产品支持。

| 能力/部件 | 当前接线与限制 | 所属方向 |
|---|---|---|
| 普通 Tool | PluginMount 与 PluginProduct 各有执行适配；独立 capability 可选入 Agent；不能覆盖系统 ID | 能力组合 |
| Role/Provider | Kernel 有选择、依赖解析和冻结机制；只交付实际接线的合同/消费者。PluginProduct 不接受 Role contract/provider 贡献 | 能力替换，限已接线领域 |
| Tool discovery | 内置与已支持的 Mount/Product 实现可选择；不允许冲突选择，停用/非法结果不静默换实现 | 能力替换 |
| Context | Nomi 已消费受支持的 Mount 来源初始/逐轮 Context；不是任意 Product Context，也不是整个 Prompt 替换 | 能力组合及明确阶段消费 |
| Skill | 精确锁定包内只读正文/资源；共享加载器与显式命令；Product manifest 不接受 Skill；不支持 shell/fork/hooks | 能力组合 |
| Agent 页面 | 显式启用后可选插件页面；共享宿主 observe/turn/cancel，宿主仍拥有会话状态；不是完整客户端、Shell 或任意 UI 区域替换 | 页面替换 |
| `before_model` | 已支持 Product Hidden action、既有顺序和真实调用；只开放该受支持阶段，不向模型增加可见工具 | 生命周期插入 |
| 模型 Provider | 内置模型使用共享请求/事件合同；插件 Provider 到生产模型回合的链路未接通 | 延期，不算已替换 |
| Browser/Computer | 有合同/适配器及内置宿主路径；不能据此宣称所有内置运行派发都已可被用户实现替换 | 新替换路径延期 |
| 规划、记忆、调度、整个 Runtime、Shell、更多 hooks | 不扩展、不预建新协议或 JS 临时实现 | 延期 |
| Rust 原生插件 | 原生 Service 后端、作者 SDK、启用入口和专属示例已删除；保留 Rust 宿主 | 不支持 |

PluginMount 的共享 Extension Host 与 Product 的独立 Service 在生命周期、权限和资源管理上有实际区别。本次保留隔离，不为表面统一做一次大型迁移。未来是否合并，要基于具体消费者，而不是强行补齐来源矩阵。

## 3. 本次实施项与停止条件

| 项目 | 实施内容 | 保留边界 / 回归重点 |
|---|---|---|
| Skill 旧链清理 | 删除退出生产的 package loader/resolver 与旧专属测试；保留共享 loader | 当前命令授权、冻结来源及只读资源仍有效 |
| Skill 发现简化 | 命令发现不加载/解码无关资源；执行装配才加载资源，共享正文和来源验证 | 损坏图片不影响命令列表，但完整装配仍拒绝非法资源 |
| Service 收缩 | 删除无生产消费者的事件流、emit、ACK 和背压分支 | 普通调用、取消、超时、存储、进程代际、权限和模型合同保留 |
| UI 默认路径 | 实验关闭时不等待插件目录/偏好；修正首个模板创建入口及偏好缓存刷新 | 默认内置启动不依赖实验请求；启用后仍检查精确发布身份 |
| UI 简化 | 撤掉专用会话事件转发/订阅协议，参考页使用宿主读取与有限轮询；删除草稿自动保存/恢复状态机 | 保留页面选择、普通 Surface/KV、宿主会话 API；不自动重试结果不明的发送 |
| 宿主装配 | 收集 Product、动态工具、Context、MCP 与会话控制依赖，单次绑定到 finalized effect scope；删除隐藏消费者重新绑定 | 取消后任务保留、未知结果阻止继续执行、重复安装拒绝、名字冲突检查 |
| 编译器边界 | 通用编译器只管引用/结构/顺序；具体 hook 合同交给运行时消费者验证 | 不放宽 Nomi 对不支持 hook 的拒绝；不新增注册中心或解释器 |

这些是代码收敛任务，不要求同时补齐延期能力。测试更新要保留有效的安全断言；不能靠删除故障测试或放宽权限让重构通过。
