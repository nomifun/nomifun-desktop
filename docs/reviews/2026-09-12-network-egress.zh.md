日期：2026-09-12。续接入口：[全局台账](audit-progress.zh.md)。

## R15-01：页面响应识别

两个新增回归在旧实现失败：application/xhtml+xml 未列入页面类型；HTML 已有明确 ASCII
开头，却因为截取的 64 字节末尾拆断中文字符而漏检。修复直接按 ASCII marker 大小写
不敏感比较，删除整段 UTF-8 解码、截取及小写字符串分配，并补标准 XHTML 类型。
保留无 Content-Type 不直接报错、JSON/SSE 不误判的原规则。

核对 nomi-providers、model-invoke 和 system/model_fetcher 的实际调用与返回语义；
没有把公共测试等同于这些业务模块的完整审计。

## R15-02：出站超时与特殊 IPv6

两个新增回归在旧实现失败：连续两跳分别低于请求超时却总计超时仍成功；保留范围、
Teredo/6to4、IETF 特殊用途及新文档 IPv6 范围被允许。

- 整次 get 使用一个 timeout，覆盖 DNS、所有跳转和 body；删除每跳重新计时。
- 独立 DNS 校验也有 15 秒上限；取消异步等待不宣称终止操作系统内部 DNS 线程。
- IPv6 限定 global-unicast /3，拒绝其中特殊用途/转换/文档范围；IPv4-mapped 沿用 IPv4
  规则。该保守策略有意拒绝 IETF 特殊用途 /23 中的特殊全球可达地址，不用于一般代理客户端。
- IP literal 直接构造 SocketAddr，不交给平台域名解析。此回归旧 Windows 实现已通过，
  不记为修复前失败；这里是消除不必要解析与平台差异。
- 保留每跳重新解析并固定全部已验证地址、禁代理/自动跳转、有界 body 及错误 URL 脱敏。
