## 当前验收边界

2026-10-28 用户决定：键盘仅随 NomiFun 主进程运行，K1 仅显示/隐藏已经运行的主窗口。主程序退出后所有按键失效，不保留设备守护进程、键盘登录启动偏好或冷启动入口。当前实现边界见 [原生四键字幕板](../architecture/native-keyboard.zh.md)。

过去独立设备服务与 Windows 恢复方案的记录位于本次改动前的 Git 历史。原始失败记录及外部测试产物保持原样；过去的服务恢复、K1 冷启动和测试数量不作为当前单进程方案的通过证据。

## 必须成立的资源约束

- 主程序只创建一个串口 owner；有界进程内通道转发按键和策略，不使用按键 IPC 端口或心跳重连。
- 正常退出确认真实系统采音停止，再关闭串口并等待工作线程结束。仅丢弃句柄不构成停止证明。
- 更新预检保留串口线程；取消、超时和回滚不恢复旧按住状态，也不自动开麦；恢复后要求新的释放屏障和 K4 按下。
- 锁屏、睡眠、设备丢失、队列溢出撤销当前按键意图；迟到 Rearmed 和旧模型结果不能恢复旧操作。
- 安装维护保留主程序生命锁、启动门禁、文件替换和回滚。退役旧服务只关停与清理精确目标安装，不创建或恢复后台设备进程。
- 字幕、录音及 ASR 仍由主程序持有；模型引用和用户正文不迁移到设备线程。

## AppImage 的明确限制

当前不自动停止来自另一临时挂载目录的运行中 AppImage，即使其外部镜像路径相同。维护入口保持拒绝未能证明归属的进程，要求先手动退出旧 AppImage 实例，再执行更新或卸载；无活动参与者时正常继续。固定安装路径的 Linux 不涉及这一跨挂载限制。本次没有增加仅适用新内核的 FUSE 身份推断，亦不宣称已取得 Linux 原生证据。

## 首次使用检查与本地麦克风检测

设置页新增页内准备步骤、现有系统权限清单和明确的阻碍原因。设备通信、权限、输入设备、模型目录、实际输入和云端转写分别作为证据；未执行的测试不标为通过。当前本机只读检查确认麦克风已授权、设备通信已就绪，但未选择当前模式的识别模型；旧页面在开麦前返回，测试入口也被同一个模型条件禁用。

本地检测复用同一原生采音 owner，最多约 5 秒采音，返回首回调、累计样本和最近窗口电平，不保留波形、不上传音频、不修改文稿或已保存设置。设置页离开、换设备或停止都只针对本次 testId；启动应答晚到会再次定向停止，尚无停止证明时不允许另一检测覆盖 owner。原生明确拒绝启动与“已接受但 IPC 失败”分别验证，不能假报停止或永久卡住。

原生合成用例覆盖：没有 ASR、没有 USB、K4 关闭仍可本地检测；已有 ASR 预热连接在检测前后没有新增连接或音频提交；已越过输入门禁的迟到回调不会把主动取消误报为采集失败；旧 testId、挂起、更新和退出继续受真实停止回执约束。两项实际竞态分别保留 RED 和 GREEN 记录。

## 调整后自动保存

按用户要求移除手动保存和放弃草稿入口。开关与选择即时排队，文本 400ms 合并、失焦与离页提交，输入法未结束的组合文字不写入。状态在滚动区域顶部持续可见，失败保留修改并可重试；本地和云端测试等待设置成功确认。

回归先 RED 后 GREEN，覆盖同一字段连续修改与 ABA、迟到 ACK、原生同值回显后落盘失败、失败重试、模式与模型原子修改、输入法结束和离页、旧页面 flush 与重挂载，以及录音时暂缓识别设置而关闭 K4 仍可提交。独立审查复现并修复：落盘失败后仅调整字号或置顶，必须保留原生当前识别值，不能用较旧已确认值回滚语言而中断录音。词典输入聚焦时保留尾换行与光标，原生规范化确认不会把第二行输入拼回第一行。
