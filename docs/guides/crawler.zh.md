# 爬虫

爬取作业从一个或多个种子 URL 出发遍历网站，抽取每个页面的正文，并归档进知识库。
在侧边栏的**爬虫**页面配置。

> 只需要抓单个页面？知识库本身就能直接接一个 URL 源，见
> [MCP 与技能](./mcp-and-skills.zh.md)。爬虫是用来跨页面跟进链接的。

## 作业做了什么

`nomifun-crawl` 是一个持久化 URL 队列加一个 worker 池：

- **队列**存在 SQLite（`crawl_jobs` / `crawl_tasks`）。每个 URL 都经过规范化并取
  指纹，同一作业内同一个页面不会重复入队。
- **worker** 原子地领取任务、持有可续期的租约、并凭围栏令牌提交结果。worker 崩溃、
  卡死或掉网时只是停止续租，它的任务会自动回到队列。没有探活机制要配置，也不需要
  手工重启。
- 发现的链接在入队前会先过作用域检查、深度限制和作业的 URL 预算。

因为队列是持久化的，抓取途中关掉应用最多只丢失正在飞行中的那几个页面。重新启动
作业就会从中断处继续。

## 新建作业

| 字段 | 作用 |
| --- | --- |
| **种子 URL** | 每行一个。抓取从这里开始，默认不能离开这些站点。 |
| **最大深度** | 距离种子最多几跳。`0` 表示只抓种子本身。 |
| **URL 上限** | 该作业最多入队多少个 URL 的硬上限。 |
| **并发数** | 跨所有站点同时抓取几个页面。 |
| **单站点并发** | 对任一站点同时最多几个请求。这条在队列分配器内部强制执行，多个 worker 也不可能突破。 |
| **请求间隔** | 对同一站点两次请求之间的最小间隔。 |
| **渲染模式** | `自动` 和 `仅 HTTP` 目前都走普通 HTTP。浏览器渲染尚未开放。 |
| **只抓种子所在站点** | 限制在种子的可注册域内（`docs.example.com` 与 `example.com` 视为同站）。 |
| **遵守 robots.txt** | 默认开启，见下方合规一节。 |
| **知识库 ID** | 页面直接写到哪里。留空则不保存内容——适合先试跑一遍。 |

## 礼貌抓取

爬虫被设计成一个守规矩的客户端。这些不是可选的附加项，而是能不能长期跑下去的前提。

- **robots.txt** 每个站点抓一次，缓存 30 分钟。`404` 表示文件不存在、整站可抓；
  `5xx` 表示文件状态未定义，按 RFC 9309 视为整站禁止。
- 站点自己声明的 **`Crawl-delay`** 若比你配置的间隔更严格，以它为准。
- `429` / `503` 上的 **`Retry-After`** 会被直接遵守（秒数形式）。没有该头时按
  1 秒起、上限 5 分钟做指数退避。
- 连续 5 次失败后该站点**熔断** 5 分钟。同一作业里的其他站点照常跑。
- `<meta name="robots" content="noindex">` 会跳过该页入库；`nofollow`（meta 或
  单条链接的 `rel`）会阻止跟进它的链接。
- 请求带可识别的 UA：`NomiFun-Crawler/1.0`。

## 保存了什么

每个页面先经过正文抽取，去掉导航、广告和页脚，再转成 Markdown，写到
`crawl/{作业名}/{页面别名}.md`，并在 front matter 里记录来源 URL。

内容哈希基于**抽取后的 Markdown** 而非原始 HTML，所以轮播广告和 CSRF token 不会
让一个没变的页面看起来变了。重新抓取时会带上 `ETag` / `Last-Modified`，未变化的
页面直接跳过重写——但它的链接照常跟进。

本期只入库 HTML。PDF、图片、JSON 响应会记为已跳过。

## 看进度

作业列表的进度条由 WebSocket 事件驱动（`crawl.progress`、`crawl.task`、
`crawl.finished`）。**URL 列表**可以看到每个页面的状态、HTTP 码和错误。

作业的结束状态：

- **已完成** —— 队列抽干了。
- **失败** —— 所有任务都失败且没有一个成功。
- **已取消** —— 你手动停止。在途任务不会被结算，它们的租约会在一分钟内到期并回到
  `pending`，重新启动作业会继续处理它们。

**重试失败**会把所有已放弃的任务重新入队并清空重试计数。适合在修好作用域规则或
恢复访问权限之后用——已经失败三次的任务在此之外是被刻意搁置的。

## 本期限制

- 没有浏览器渲染。选了浏览器模式的作业会直接失败，而不是悄悄抓回一个未渲染的空壳。
- 仅单机。claim 协议本身已经是多节点安全的，但远程 worker 通路还没接。
- 还没有定时重爬。
- worker 池按作业独立，同时跑多个作业时并发数是相加的，没有全局上限。
