# 办公工作台：飞书

从左侧「常用 → 办公」进入。首期提供飞书文档、日程、任务和多维表格，
支持 Tauri 桌面及桌面 WebUI。所有业务操作通过官方飞书 CLI 完成。
组件和账号位于 NomiFun 后端机器，可能与浏览器所在电脑不同。

## 连接飞书

连接弹窗分为三步：

1. **准备环境**：检查运行主机和组件。已有兼容安装优先复用；缺失时点击准备，
   之后才下载所需组件，CLI 不进入 NomiFun 安装包。
2. **连接飞书**：打开官方配置或登录链接，完成企业应用和用户连接。
   已有 profile、指定程序路径和手工应用信息放在高级选项。
3. **读取权限**：选择需要浏览的文档、日程、任务或多维表格，可稍后再授权。
   企业管理员可能需要先审批；写权限在实际保存时按需申请。

第二步仅用 CLI 的 `offline_access` 完成身份登录，不申请文档、任务等业务权限。
第三步跳过后仍保持已登录，首次使用相应能力时再按需授权。

补充权限后回到原输入，点击保存才提交。更换应用、用户或 profile 后，旧表单不能继续写入。
取消授权需要等待原进程收尾，之后才能重新开始。

高级选项提供只读更新检查、恢复自动发现，以及可复制到自己终端的官方完整向导命令。
兼容基线是 1.0.98。版本检查不安装或同步 Skills；外部安装继续由原工具链维护。
完整向导可能为其他 Agent 全局安装 Skills，工作台不会静默执行。
密钥与 token 留在 CLI 自己的存储中。

## 文档

搜索或粘贴链接打开有权访问的文档。新建时填写标题，正文可留空。
最近入口只记住实际打开过的资源定位、标题和时间，重新打开仍读取飞书当前内容。

在文档内选择一个可编辑的普通段落，修改后点击**保存**。
工作台使用真实段落 block 和原版本；标题、复杂版式、表格等内容保持只读，可在飞书继续编辑。
没有可靠的段落与版本信息时只提供阅读；只有确认正文为空时才允许新增首段。
源版本变化会要求重新读取，并保留当前输入。

保存结果未解决时，整篇文档暂停新的修改，换段落也不能重复提交。

## 日程与任务

个人日程使用明确时间和时区，不自动添加参与者或视频会议。
任务填写标题、真实负责人和可选截止日期，创建人、负责人、清单分别显示。
「我负责」与「我创建」是不同列表；指定共享清单不会自动授予成员编辑权限。
完成或重新打开任务同样需要写权限。

## 多维表格

粘贴含 `/base/` 路径和 `table` 参数的完整数据表链接；不完整时先在飞书选择表再复制。
字段、可选项、记录身份和分页来自实际响应。

选中记录、填写支持的简单字段后点击一次**保存**，每批最多 200 条。
系统、公式和复杂字段不会作为普通值开放写入。保存前会检查原值，但不能阻止其他客户端同时修改。

批次接受后先显示**待核验**，按原记录和字段读回确认。
暂未看到目标值不等于未执行；待核验行不可再次选中写入，可以打开原操作继续核验。

## 保存结果与停用

表单直接保存，不增加中间提交步骤。操作记录只包含工作台发起的请求。

- **已确认**：保留真实资源标识和原回执。
- **明确未执行**：可修正这些项目后显式提交新请求，旧记录保留。
- **待核验**：可能已经执行，按原请求或目标核验，不自动重发。
- **部分完成**：逐项展示，成功项和未知项不能混入新的提交。

响应丢失时按原请求 ID 恢复结果；刷新、离开页面或重启不会再次写入。
没有任务 GUID 或确切回执，不能靠同名搜索确认创建。原结果和后续核验分别保留。

停用停止新业务，保留连接、最近入口和历史回执。已开始的远端操作可能仍完成。
停用不等于撤销飞书授权，撤销需到飞书管理。

现有[飞书 Skill](mcp-and-skills.zh.md)继续使用 canonical 进程工具。
缺失组件时通过同一个工作台准备；工作台选择的路径和 profile 不会自动注入 Agent 会话。
