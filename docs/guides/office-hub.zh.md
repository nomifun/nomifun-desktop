# 办公：飞书

从左侧「服务 → 办公」进入。首期提供飞书文档和多维表格，
支持 Tauri 桌面及桌面 WebUI。所有业务操作通过官方飞书 CLI 完成。
组件和账号位于 NomiFun 后端机器，可能与浏览器所在电脑不同。
页面直接展示文档列表。

## 连接飞书

页面根据当前连接状态显示下一步：

- **未安装组件**：主页面显示安装入口和说明。点击后才下载连接组件；安装中可查看进度，失败可重试。
  已有兼容安装直接复用，损坏或不兼容的安装会提示修复。
- **应用未连接**：选择已有连接，或打开飞书官方流程配置应用。
- **未登录或登录过期**：在浏览器完成飞书登录，再返回页面查看当前账号。

基础登录只申请 `offline_access`；文档权限在使用相应内容时申请。
成功登录后即可使用页面，没有必须完成的权限勾选步骤。

## 账号与更换登录

点击页头当前账号，默认打开账号信息和管理操作：

- **更换账号**：确认退出当前登录后，重新打开飞书登录流程，选择要使用的账号。
- **退出登录**：确认后只退出当前连接，不会自动重新登录。
- **切换连接**：选择另一个已配置的飞书应用连接。

退出保留应用配置和已提交请求结果；重新登录不用重新安装连接组件。
当前仍有保存操作或授权流程未结束时，需先等待它们完成或取消授权并等待收尾。
官方 CLI 的退出会清除一个连接内保存的全部用户，因此保存了多个用户的连接不会被自动退出；
页面会提示使用“切换连接”，避免误退出其他账号。

权限区按文档显示已授权与待授权的能力，不默认勾选权限。
补充权限后回到原输入，点击保存才提交。更换应用、用户或 profile 后，旧表单不能继续写入。
取消授权需要等待原进程收尾，之后才能重新开始。

组件主机、版本、路径、只读更新检查和停用连接放在高级设置中。
**停用连接**停止新的业务操作，保留登录状态；它与退出登录不同。
兼容基线是 1.0.98。版本检查不安装或同步 Skills；外部安装继续由原工具链维护。
高级设置中的官方完整向导仅供复制到自己的终端执行，可能为其他 Agent 全局安装 Skills，
办公页不会静默执行。密钥与 token 留在 CLI 自己的存储中。

## 文档

浏览有权访问的文档，按标题搜索或按类型筛选；查询和筛选先作用于服务端集合，再分页。
点击文档名或**浏览器打开**，也可粘贴飞书／Lark 官方资源链接。
正文在飞书中阅读和编辑。

新建只填写标题，创建空白文档后回到列表，正文在飞书中编写。
删除前显示确切标题和链接，确认后才提交。只有支持的云文档类型提供删除入口，
知识库节点和多维表格通过浏览器打开。删除结果未解决时，同一资源不能再次写入，
可打开原操作核验结果。

## 多维表格

在文档页选择**多维表格**类型筛选，搜索后通过浏览器打开。
NomiFun 不提供独立的多维表格页面或记录编辑表单。

## 保存结果

表单直接保存，结果在当前表单中提示；未解决的操作可从原资源继续核验。

- **已确认**：保留真实资源标识和原回执。
- **明确未执行**：可修正这些项目后显式提交新请求，旧记录保留。
- **待核验**：可能已经执行，按原请求或目标核验，不自动重发。
- **部分完成**：逐项展示，成功项和未知项不能混入新的提交。

响应丢失时按原请求 ID 恢复结果；刷新、离开页面或重启不会再次写入。
没有确切回执，不能靠同名搜索确认创建。原结果和后续核验分别保留。

已开始的远端操作即使停用连接也可能继续完成。停用不等于退出登录或撤销飞书授权。

现有[飞书 Skill](mcp-and-skills.zh.md)继续使用 canonical 进程工具。
缺失组件时通过同一个办公连接准备；办公页选择的路径和 profile 不会自动注入 Agent 会话。
