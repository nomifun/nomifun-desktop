# SSH 远程会话

SSH 远程会话让你把一台远程 Linux 主机的连接信息交给 NomiFun，然后在普通的聊天
会话里与 agent 协作，由它代你操控那台主机——跑命令、读写文件、搜索目录、安装依赖。
本地机器完全不参与：整场会话的工作都发生在远程主机上。

> NomiFun 是 local-first 的，除了你配置的 LLM 调用外不向任何地方发送数据。SSH 是
> 你按主机主动开启的唯一例外——一条通往你自己机器的出站连接。凭据加密存储于本机，
> 永远不会以明文返回给界面。

## 主机簿

打开 **设置 → 远程主机**。一台主机是一份已保存、可复用的连接档案，归安装主人所有：

- **显示名称**、**主机**、**端口**（默认 22）、**用户名**。
- **认证方式**——四选一：
  - **密码**
  - **私钥**（PEM 或 OpenSSH 格式），可带**口令（passphrase）**
  - **证书**（OpenSSH 证书 + 对应私钥）
  - **SSH agent**——认证委托给你机器上已在运行的 ssh-agent，NomiFun 不经手密钥本体
- **sudo 密码**（可选）——见下文 [sudo](#sudo)。

所有密文字段以 AES-256-GCM 加密存储。重新打开主机时，已存的密文显示为 `***`；保持
不动即沿用，输入新值则替换。有会话绑定该主机时，删除会被阻止。

**测试连接** 会拨号并跑一个最小探针，报告成功或确切的失败原因。

## 开始一个会话

在主机行点 **新建会话**。NomiFun 会创建一个绑定该主机的聊天会话并打开它。SSH 会话在
会话列表里作为独立种类出现，与本地普通工作分开。

从这一刻起，agent 的工具操作的是远程主机：

- `Bash` 跑在一个**长驻远程 shell** 里——`cd`、`export`、激活的 virtualenv 等 shell
  状态在会话内跨命令保持，和真正的交互式终端一样。
- `Read`、`Write`、`Edit` 走 **SFTP**，原子写（临时文件 + rename）并保留权限位。文件
  编辑绝不用 shell 字符串拼接。
- `Grep`、`Glob` 搜索远程目录（有 ripgrep 用 ripgrep，否则 grep）。

## 主机密钥

首次连接一台主机时，它的密钥会记入你自己的 `~/.ssh/known_hosts`（首连信任，等价于
OpenSSH 的 `accept-new`）。若某主机的密钥之后发生变更，连接会被阻止——这是防中间人
攻击的常规手段，且不会自动接受变更，因为 `known_hosts` 是你与自己的 `ssh` 共用的文件。

## sudo

如果你为主机设置了 sudo 密码，agent 就能执行需要提权的命令（`sudo systemctl restart
nginx` 等）而不被打断。密码由传输层在识别到 sudo 提示符时注入：它直接进入远程 shell 的
输入，**永远不会**出现在命令文本、会话记录或发送给模型的请求里。每条命令只注入一次、
绝不重试，因此密码错误会停止而不会触发 PAM 锁定。远程账号若是免密 sudo，此项留空即可。

## 安全姿态

agent 操控远程主机的**权限与它在本地一致**——这是刻意设计。除了本地执行本就有的之外，
不加任何额外审批闸门或破坏性命令拦截；机器是你的，你自己负责。请谨慎决定连接哪些主机、
以及是否为生产系统保存 sudo 密码。

NomiFun 保证的是：凭据加密存储、永不以明文返回界面、永不进入会话或模型请求、且强制
主机密钥校验（首连 accept-new，变更即阻止）。

## 本版不做

从 `~/.ssh/config` 导入主机、实时远程输出终端面板、ProxyJump/跳板机、MFA/
keyboard-interactive 认证，都留待后续阶段。远程目标假定为 POSIX Linux 主机。
