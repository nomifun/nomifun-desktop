# 连接与设备

在左侧导航打开 **连接与设备**（`/connections`），按你要完成的任务选择：

| 任务 | 入口 | 获得的访问方式 |
|---|---|---|
| 用手机访问 Desktop | **连接手机** | NomiFun Mobile 专用的一次性配对码与独立设备凭据 |
| 用另一台电脑访问 | **其他电脑浏览器** | WebUI 访问地址、管理员登录或一次性浏览器登录链接 |
| 让外部 Agent 或工具调用 Desktop | **外部工具接入** | MCP / REST 配置与安装访问令牌 |

Desktop 是业务数据与执行的权威端；Mobile 是连接客户端，NomiRelay 是可选网络承载。
IM 渠道与实体机器人在每位伙伴的 **渠道与机器人** 中配置。两处提供互相跳转的入口。

共享 WebUI renderer 支持 880×600 及以上的桌面窗口与桌面浏览器。
手机使用独立的 NomiFun Mobile，不通过手机浏览器运行 Desktop renderer。

旧 `/open-capabilities` 和 `/settings/webui` 会跳转到浏览器任务；
`/settings/tools` 会跳转到外部工具任务。

## 在同一网络连接手机

1. 启动 Desktop，在 **连接与设备 → 连接手机** 确认显示的是要连接的 Desktop。
2. 选择 **同一网络**，点击 **启用同网访问**。
3. 选择手机能够访问的 Desktop 地址。多网卡或 VPN 环境中，选择与手机网络连通的地址。
4. 点击 **生成手机配对码**。
5. 在 NomiFun Mobile 中选择 **添加 Desktop**，扫描二维码或粘贴手机配对链接。
6. 等待 Desktop 显示“手机已完成配对”，并在下方 **已配对手机** 列表核对名称。
   配对成功表示设备凭据已签发；手机的业务连接还需完成 Desktop 身份与协议握手。

配对码短时有效且仅可兑换一次。页面显示剩余时间；已使用或过期后不再显示二维码。
生成新的配对码会使之前未使用的配对码失效。若 Desktop 无法完成配对（例如已配对手机数量达到上限），页面会提示原因，而不会显示配对成功。
添加下一台手机时点击 **生成新的配对码**。每台手机获得独立凭据，模型密钥和数据库仍保存在 Desktop。

手机与 Desktop 需使用同一可达网络。离开该网络后，同网地址无法使用；
先配置跨网络中继，再在 Mobile 中添加相应入口。

## 通过中继跨网络连接手机

使用自己托管的 NomiRelay，或向中继管理员索取 Console 地址和接入配对串。

1. 在 **连接手机** 选择 **跨网络（中继）**。
2. 输入 Relay Console 地址并点击 **打开控制台**。尚未部署时使用旁边的部署指南。
3. 在 Console 为 Desktop 创建 v2 接入配对串，粘贴到 Desktop，点击 **连接中继**。
4. 确认状态为 **中继在线**，并且 Desktop 接口与跨网入口均可用。
5. 生成手机配对码，在 Mobile 中扫码或粘贴链接，核对 Desktop 身份并完成配对。

中继接入配对串是给 Desktop 的；手机配对码是给 Mobile 的。
Mobile 不需要中继管理员凭据或 `nfagent` 的接入密钥。
旧 v1 中继接入会提示升级与重新配对，不能用于新的设备凭据流程。
Desktop 同一时间只保留一个中继连接。要改用其他中继或新的接入配对串，请先解除当前连接。

手机配对码仅在点击“生成”时产生；连接或重启中继不会生成配对码。

- **暂停跨网访问**：关闭中继连接并持久保存暂停选择；重启 Desktop 后不会自行恢复。
  手机凭据和已开启的同网访问保留。
- **重新连接**：恢复已保存的中继接入。若接入结果尚未确认，使用此动作核实，避免反复创建新接入。
- **解除中继连接**：v2 会先撤销服务端接入，再清理本机中继配置；中继无法确认解除时本机保留配置供重试，
  此时可选择 **仅在本机忘记**，不联系中继即删除本机配置，旧的中继端连接需在 Relay Console 撤销。
  它不删除 Desktop 的业务数据，也不代替独立手机撤销。
- **仅在本机忘记** 也在本机无法读取已保存的中继配置时提供（例如数据目录迁移到了其他 Windows 账户）。
  手机凭据和同网访问保留。
- 对旧 v1 接入，本机只能忘记配置，还需在 Console 撤销旧 Agent 凭据。

## 管理已配对手机

**已配对手机** 列表显示已授权设备与最近使用时间。它不是实时在线列表。

Desktop 与 Mobile 均需支持连接协议 2。Mobile 在安全存储中为每个 Desktop 保存随机安装标识，
并将它与访问凭据分开管理。再次连接、切换同网与中继地址，或使用相同安装标识重新配对时，
仍保留同一条设备记录。重新配对或密码登录会替换该设备的凭据，并断开使用旧凭据的连接。
显示名称相同但安装标识不同的手机仍是独立设备。

对于旧版保存的连接，Mobile 可在重新配对或密码登录时，用仍有效的旧设备凭据精确认领原记录。
历史重复记录没有安装身份，不能按名称或最近使用时间安全合并，请明确移除过时记录。
清除 Mobile 的安全存储会丢失安装标识；若也没有有效旧凭据，下次配对会生成新记录，
原有过时记录同样需要明确移除。

点击某台手机的 **移除手机** 并确认，可撤销该设备的凭据和现有连接。
其他手机继续可用，Desktop 的会话、任务和文件保留。被移除的手机需重新扫码才能恢复使用。

在浏览器会话中（包括专用 Web 服务）修改所有者密码，会注销所有浏览器会话和全部已配对手机，之后需要重新配对手机；
在 Desktop 应用内修改密码不会影响已配对手机。

手机凭据提供此 Desktop 所有者范围内的任务、会话与工具访问权限。
只为受信任的自用手机配对，妥善保管二维码与链接。

## 在其他电脑的浏览器访问

打开 **其他电脑浏览器**，在 Desktop 应用内启用 WebUI 后，将访问地址复制到另一台电脑的桌面浏览器。
使用管理员账号密码登录，或复制此任务中的一次性 **二维码登录** 链接。

浏览器登录码与 Mobile 配对码用途不同。浏览器链接以 `/qr-login?token=…` 为入口；
Mobile 使用包装 `/device-pair?token=…` 的 `nomifun://pair` 链接。

LAN WebUI 默认端口为 `25808`（开发 channel 通常为 `25809`，多实例模式为 `25810`）。
以界面实际显示的地址为准，不要手动假设端口。首次启用可能只显示一次初始管理员密码，
随后可在账号面板修改密码或用户名。若在启用 WebUI 之前已配置跨网访问，浏览器任务会显示
密码已设置；请先在账号面板使用密码操作设置密码，再从浏览器登录。

Desktop 的首次凭据设置只能由应用内的受信任客户端执行；仅连接回环地址、持有浏览器或手机令牌、
伪造页面 Origin 都不能初始化所有者密码。同网与中继监听会在开放前配置访问密码。

WebUI 开关只控制同网监听。中继有独立回环入口和启用状态，暂停中继不等于关闭 WebUI。
关闭 Desktop 或系统休眠后，它不能继续执行手机发来的任务。

## 已经在使用专用 Web 服务

通过桌面浏览器登录 `nomifun-web` 的安装所有者，可以在 **连接手机** 中生成配对码、读取列表和独立撤销设备。
二维码使用当前站点的真实地址。手机必须能够访问该地址；若站点通过 localhost 或 127.0.0.1 打开，
请改用局域网 IP 或部署域名后生成配对码。

浏览器不能操作 Desktop 的 Tauri 监听与中继进程。专用服务的端口、TLS 与进程生命周期
按 [Web 服务器部署](./web-server-deployment.zh.md) 配置。
专用 `nomifun-web` 在要求登录的模式下保留首次设置流程；部署时先完成所有者设置，再开放给非受信任访问者。
设备凭据不允许为其他设备签发或撤销授权，管理这些操作需使用所有者账户或 Desktop 应用。

## 外部工具接入

在 **外部工具接入** 选择需要的 MCP / REST 能力域，复制接入配置。
安装访问令牌在 Desktop 应用中签发，首次生成仅显示一次；可单独吊销。
该令牌属于安装，独立于手机凭据与浏览器会话，不选择或冒充某个伙伴。

## 常见问题

- **找不到入口**：左侧全局 **连接与设备** 管理手机、浏览器和外部工具；
  伙伴的 **渠道与机器人** 管理 IM 与实体机器人。
- **手机打不开同网地址**：检查双方网络、所选网卡、VPN 路由与主机防火墙。
  localhost 和 127.0.0.1 只能由当前主机访问。
- **中继在线但手机不可用**：先核对跨网入口健康状态；再核对手机的 Desktop 身份、协议版本和设备授权。
  “中继在线”仅表示网络传输状态，不等于手机已完成配对。
- **配对码过期或已使用**：生成新的手机配对码，不要重复兑换旧码。
- **Desktop 升级后版本不兼容**：升级 Mobile 至支持当前协议的版本；会话历史仍以 Desktop 的 canonical Agent Session 为准。
- **手机已移除**：从 Desktop 重新生成配对码。移除其他手机或重启中继不会恢复该手机的授权。
- **中继无法确认解除，或本机无法读取已保存的中继配置**（例如数据目录迁移到了其他 Windows 账户）：
  选择 **仅在本机忘记** 清除本机状态后重新连接，并在 Relay Console 撤销旧连接。
- **界面与安装版本不一致**：在桌面浏览器中强制刷新页面，重新加载当前安装提供的 UI。

认证监听仍具有文件、工具和 Agent 执行权限。LAN HTTP 用于可信网络；跨公网使用正确的 TLS 中继或专用 Web 服务部署。
任何能访问该地址的人都可读取安装标识符与用于配对检查的协议版本。同一网络中还会显示电脑名称；
通过中继访问时显示“NomiFun Desktop”，除非用 `NOMIFUN_DESKTOP_NAME` 为所有地址设置名称。
不要发布包含有效配对码、安装令牌或密码的截图。
