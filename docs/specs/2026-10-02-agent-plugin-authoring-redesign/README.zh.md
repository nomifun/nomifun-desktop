# 插件与小程序

更新：2026-10-08。本页描述当前产品，实施情况见 [实施说明](IMPLEMENTATION.md)。被替换的设计和历史验收记录通过 Git 查询。

## 产品目标

用户能从一个清晰的入口找到作品、直接使用、用自然语言创作、随时继续修改，并管理自己的本地内容。创作成果保存在本机，完成创作后即可使用。产品不提供发布流程、版本管理、最近检查或额外安装审批。

插件与小程序支持界面、后台能力以及二者结合。用户可以创建自己的工具、接入 Agent 能力和主机扩展点；纯界面作品无需先理解 Action、Binding、Artifact、DataRoot 或权限术语。

## 内容组织

入口使用统一的桌面工作台：顶部切换作品、创作记录和回收站，内容区展示作品卡片与检索条件。常用和停用通过筛选直接查看，小程序与后台能力作为类型筛选。启用和停用是作品的操作状态，运行问题直接在相关作品中说明，不另设检查中心。

用户可创建、重命名、删除分类，将作品归入分类。删除分类仅移除归类关系，不删除作品。分类、常用和作品别名使用现有 Plugin Library State；持久化失败应显示可重试的错误，不能只改变本地界面造成假成功。

搜索覆盖作品名称、说明和可识别的内容身份；分类和类型筛选与搜索组合使用。检索无结果提供清除条件的入口。空库提供创作和导入入口，不展示空表格、无数据的统计或空任务区。

作品使用统一尺寸、留白和操作位置。名称与说明为主要信息，类型与启用状态为次要信息；机器标识、源码、配置与接入详情收进高级区域。常用作品能够从侧栏直接打开。

## 创作与继续

新建与编辑都在“插件与小程序” Tab 的创作工作台完成。用户选择已有 Agent 和模型，用一句话描述需求；页面保留需求、执行过程、产物与预览。首次进入以需求输入为中心，示例可直接填入输入框。高级 Agent 配置保持可达，但不占据默认页面的视觉中心。

创作记录包含还未产生文件的任务和已有产物的任务。用户中断创作后可重新打开原记录，查看已保存的文件并继续同一 Session。完成的作品保留创作记录，后续修改从作品进入；无需用户另行确认安装或维护发布记录。

文件与预览来自真实插件接口。运行或保存失败在当前上下文给出原因与重试入口；不得显示伪造的可用状态。预览与正式作品共享同一 Surface 组件，交互经实际 SDK、Bridge 和本地存储完成。文件、执行细节和代码可折叠查看，不将完整技术 JSON 默认铺在页面中。

## 使用与管理

打开作品优先展示可操作的小程序界面。后台作品优先展示能力及可执行入口。修改、启用、设置、导出和移除集中在一致的位置；管理详情按需展开。作品数据在停用、关闭页面和重新启动程序后保留。

导入仅需选择源码目录、ZIP 或作品备份，查看作品概览，点击“导入并使用”。已存在的作品可以更新内容，也可以作为独立副本导入；独立副本使用新的身份和数据。导入备份恢复其中的本地数据与配置，需要凭据时选择已保存的账号或连接。

设置和直接运行优先使用命名参数表单，基本文本、数字、选项和开关无需填写 JSON。复杂参数仍提供完整 JSON 与结构说明；表单和 JSON 共用同一份内容，切换不会丢失参数。主机能力开关收进高级设置。凭据仅引用现有 Host Credential Store，不把秘密值写进作品配置或导出内容。

回收站保留作品与数据，用户可以恢复或永久删除。永久删除明确告知数据后果；普通创作、导入和使用不增加无意义的确认步骤。

## 唯一事实链

工作台复用现有 canonical AgentSession、Turn、Event、Payload、Effect 和 Nomi Runtime。SessionPurpose 从 canonical opening 事实读取；创作记录使用同一 Session 身份，没有独立 worker、私有 transcript、插件 checkpoint 或第二绑定账本。

普通会话不挂载插件成果、预览 iframe 或插件事件订阅。欢迎页不承担创作中转。当前创作 Session 直接在插件工作台读取与恢复；普通会话产生的当前代草稿通过新的 PluginAuthoring Session 继续创作，只使用保留的作品文件和配置，不读入或迁移原 Agent 历史。已可使用的作品可开启新的编辑 Session。产品页面归属不会转换旧 Agent 数据，也不会放宽 canonical 历史和原生 checkpoint 的完整性要求。

创作沿用用户所选 Agent 的现有能力，保留其 Skill、MCP 和资源配置。插件工作台不设置只许使用插件工具的独立能力上限，也不设置三次失败或 64 步的插件专属暂停规则。原生 Session 的权限、预算、模型切换和 checkpoint 机制保持一致；用户可以按需求调用其他能力并自由继续创作。

内部并发修订号、内容摘要和存储世代用于正确读取及原子写入，不作为用户需要管理的版本产品。文件替换和数据库变更失败时恢复实际变更前的数据；关闭或替换 Surface 后，迟到响应不能覆盖新页面或新作品。

## 桌面布局与验证

支持 Tauri 桌面和桌面级 WebUI，最低视口为 880×600。工作台根据内部容器宽度调整导航密度与面板排列；正文和长列表可独立滚动，主要操作始终可达。导入与设置弹窗采用一致的宽度、组件大小与滚动区域。使用现有主题颜色支持明暗主题，不增加移动布局或触摸分支。

验证应覆盖分类和常用持久化、搜索筛选、创作入口与任务找回、中断后继续、作品实际运行、导入和设置、关闭重开与数据保留。先运行受影响的定向测试、typecheck、i18n 与 Desktop UI Boundary；需要后端变更时补充对应 Rust 测试。模拟数据用于布局检查时必须与真实插件运行验收区分。
