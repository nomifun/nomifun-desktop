敏感文件检查

在 Nomi 调用工具前，先检查这次操作是否直接引用敏感文件。

这份草稿不会自动生效
  1. 按业务需要调整检查规则，然后点击宿主的“保存”。
  2. 返回 Agent 工作台，将“敏感文件检查”选入能力列表并保存。
  3. 使用该 Nomi Agent 新建会话。既有会话保留原配置。

示例会阻止参数中直接引用 .env、id_rsa 或 id_ed25519 的操作，并显示原因。

检查只接收工具名称及脱敏后的参数。它可以拒绝操作，不能批准权限，也不会改变工具参数。

这是可编辑的业务规则示例，不是完整的命令安全策略。文件名变换等间接引用不在示例识别范围内；平台原有权限仍然有效。此页面不执行测试工具、不访问你的文件。
