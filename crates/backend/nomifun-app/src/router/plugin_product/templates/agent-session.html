Waiting for authorized Session identity…

Draft text and pending request identity are saved in this plugin's private storage, separately for each Session (up to 32,000 characters). Wait for “Draft saved” before changing views; offline or unconfirmed edits remain local. Restoring a pending request never sends it automatically. These records are not Session history and remain plugin data until cleared; use the host's built-in view for attachments, fork/delete and other unsupported controls.
